#+title: pecciolidavide: homepage accademica

Sito scritto in Org mode ed esportato in HTML in =_build/=, da dove pubblica Netlify.

* Struttura
| Percorso         | Cosa contiene                                                         |
|------------------+-----------------------------------------------------------------------|
| =content/*.org=   | le pagine; =foo.org= diventa =foo.html= (i file =_*.org= non si pubblicano) |
| =static/=         | copiato tale e quale in =_build/= (=css/=, =img/=, =files/cv.pdf=, ...) |
| =publish.el=      | configurazione di =org-publish= (menu, footer, opzioni di export)      |
| =Makefile=        | =make= builda, =make clean= svuota =_build/=, =make serve= apre su localhost:8000 |
| =netlify.toml=    | Netlify pubblica =_build/= senza build                                |
| =.dir-locals.el=  | fa sì che =C-c c c= in Emacs lanci =make= nella radice                 |
| =_build/=         | output generato: non si modifica a mano, ma si committa                |

* Build
- Da Emacs: =C-c c c= da qualunque file della repo, poi =RET=.
  La prima volta Emacs chiede se fidarsi di =.dir-locals.el=: rispondi =!=.
- Da terminale: =make=.

* Link tra pagine
- Ad altra pagina: =[[file:research.org][Research]]= (diventa =research.html=).
- A una sezione: =[[file:research.org::#papers][Papers]]=, con =:CUSTOM_ID: papers= sulla heading.
- A un file statico: =[[file:files/cv.pdf][CV]]= (il percorso è quello dentro =static/=).

* Pubblicare
1. =make=, controlla con =make serve=.
2. Commit di sorgenti e =_build/=, push su =main=: Netlify pubblica da solo.
